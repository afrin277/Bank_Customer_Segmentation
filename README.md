# Bank Customer Segmentation

## Project Overview
An interactive Power BI dashboard for exploring customer demographics, transaction behavior, customer segments, and profitability and risk indicators.

## Dashboard Pages
1. Customer Demographics Analysis
2. Transaction Behavior Insights
3. Customer Segmentation Analysis
4. Profitability & Risk Indicators

## Tools Used
- Microsoft Power BI
- CSV dataset
- Data visualization and dashboard design

## Repository Structure
- `data/` — Source transaction dataset
- `powerbi/` — Power BI report
- `screenshots/` — Dashboard screenshots
- `README.md` — Project documentation

## Dataset
The project uses the `bank_transactions.csv` dataset. Review the dataset's source and usage terms before redistributing it.

## How to View
1. Download the `.pbix` report from the `powerbi/` folder.
2. Open it using Microsoft Power BI Desktop.
3. If prompted, update the data source path to the downloaded CSV file.
4. Refresh the data if required.
