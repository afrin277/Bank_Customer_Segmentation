# 🏦 Bank Customer Segmentation & Transaction Analysis

An interactive **Power BI dashboard** designed to analyze bank customer demographics, transaction behavior, customer segments, and profitability indicators. This project transforms transaction data into meaningful insights to support data-driven banking decisions.

## 📌 Project Overview

Understanding customer behavior is essential for banks to improve customer engagement, identify valuable customer segments, and make informed business decisions.

This project uses data analysis and interactive visualizations to explore customer and transaction patterns through four dashboard pages.

## 🎯 Project Objectives

- Analyze customer demographics and characteristics.
- Explore banking transaction behavior and spending patterns.
- Understand customer segments and their differences.
- Examine profitability and relevant risk indicators.
- Present key insights through interactive Power BI visualizations.

## 📂 Dataset

The project uses `bank_transactions.csv` as its input dataset.

The dataset supports the customer and transaction analyses presented in the dashboard. Please refer to the dataset's original source and usage terms before redistributing it.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://www.microsoft.com/en-us/power-platform/products/power-bi/desktop).
3. Open `powerbi/Bank Customer Segmentation.pbix`.
4. If Power BI requests the source file, update the data source path to the downloaded `data/bank_transactions.csv`.
5. Refresh the data if required.
6. Explore all four dashboard pages and interact with the available filters and visuals.

## 💡 Business Value

This dashboard demonstrates how data visualization can help banking teams:

- Understand customer characteristics and behavior.
- Compare customer groups.
- Identify transaction trends.
- Review profitability-related indicators.
- Communicate analytical findings through an interactive report.

*The dashboard supports exploratory analysis; its findings should not be treated as verified financial or credit-risk assessments without appropriate validation.*
